LLM Burst Options

Trusted Clicks (CDP)

Trusted Clicks are required and always enabled
The extension now requests Chrome's Debugger permission by default to simulate trusted clicks needed by the ChatGPT UI when activating Deep research.
Trusted clicks are enabled by default.

Gemini API

Stored locally via chrome.storage.sync. Used for auto-naming titles.
Leave blank for default (models/gemini-2.5-flash-lite). Prefix "models/" is added automatically if missing.

Defaults

Default providers
These defaults are applied to the popup when it opens.

Keyboard Shortcuts

Global commands (remappable):
- Open popup: Command/Ctrl+Shift+U (default)
- Open popup with Research: no global default
- Open popup with Incognito: no global default
- Open Launcher window: not set by default
In the popup: Research = Cmd/Ctrl+Shift+E; Incognito = Cmd/Ctrl+Shift+I
Set yours at chrome://extensions/shortcuts
Changes are saved to your browser profile and sync across Chrome (if enabled).
